Lyapunov Chaos Estimator

Measure how fast nearby paths separate in a chaotic system.

📘 Theory

In chaotic systems, nearby trajectories diverge exponentially:

Δ(t) ≈ Δ₀ e^{λt}

The constant λ is the Lyapunov exponent.

Taking logarithms:

ln Δ(t) = ln Δ₀ + λ t

  • λ > 0 → chaos
  • λ = 0 → marginal stability
  • λ < 0 → stable fixed point
